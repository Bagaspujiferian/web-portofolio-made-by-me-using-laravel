Ringkasan Eksekutif & Arsitektur SistemAplikasi ini adalah Interactive 3D Developer Portfolio & Dynamic CV CMS untuk Bagas Puji Ferian (BagasDev.) yang mereplikasi seluruh tampilan dan interaksi alfari.my.id menggunakan mesin backend PHP 8.2+, Laravel 12, dan MySQL untuk di-deploy secara gratis di Vercel.Backend & Database: PHP 8.2+, Laravel 12, Eloquent ORM (dengan SoftDeletes), dan Cloud MySQL (TiDB Serverless / Aiven) yang dioperasikan melalui vercel-php runtime.Frontend Public View: Laravel Blade, Tailwind CSS, Alpine.js, Lucide Icons, Devicon (ikon berwarna teknologi), serta Three.js / Vanilla-Tilt.js untuk simulasi fisika kartu ID gantung 3D.   Frontend Admin Panel (CMS): Dashboard berbasis Tabler UI untuk mengelola profil, proyek, sertifikat, pesan kontak, serta moderasi komentar pengunjung.Penyimpanan Media Serverless: Foto profil komentar (maksimal 5 MB) dikompres otomatis menjadi string Base64 WebP ringan di database MySQL agar berjalan mulus di sistem file read-only Vercel.   2. Bedah Spesifikasi Visual & Efek Khusus (UI/UX)Empat elemen visual khas dari referensi desain yang wajib direplikasi secara presisi di lapisan CSS dan JavaScript:Liquid Glass Refractive Floating Navbar: Navbar kapsul melayang (fixed top-4) dengan latar backdrop-blur-xl, efek distorsi kaca cembung (SVG displacement filter & chromatic aberration di tepi kapsul), teks BagasDev., pemisah vertikal, tombol mute/play musik latar (🔊), dan tombol menu hamburger (≡).   3D Hanging Lanyard ID Card: Kartu tanda pengenal bergaya poster retro yang tergantung pada tali lanyard hitam bertuliskan nama developer dan pengait besi perak, dapat diayunkan dengan sentuhan atau kursor.   Interactive Spider-Man / Alter-Ego Spotlight Portrait: Foto potret setengah badan dengan lapisan wireframe dan kostum Spider-Man transparan beserta titik node cyan menyala yang bereaksi mengikuti pergerakan jari atau mouse.   Metallic Specular Glowing Borders: Bingkai kartu berukuran 1.5px dengan efek pantulan cahaya metalik (emas/putih/biru) di sudut kartu proyek dan kartu angka statistik.   3. Spesifikasi Fungsional Per Bagian (Urutan Atas ke Bawah)Halaman utama (resources/views/portfolio/index.blade.php) dan halaman detail proyek (resources/views/portfolio/show.blade.php) wajib memuat 8 bagian berurutan berikut:A. Bagian 1: Hero Section & 3D Lanyard CardKartu ID Gantung 3D: Menampilkan badge "BACKEND", logo institusi di kanan atas, teks besar "DEVELOPER", teks vertikal "SOFTWARE ENGINEER", foto profil, label nama "BAGAS PUJI FERIAN", serta strip bawah "PORTFOLIO | Don't repeat yourself" dengan cincin besi di sudut bawah.   Tipografi Hero & Efek Mengetik: Teks gradien biru "Welcome to" diikuti teks putih tebal "My Portfolio" dan teks animasi ketik otomatis (Typed.js) dengan kursor biru berkedip |.   Paragraf Pembuka & Tombol Ganda: Teks deskripsi passion ngoding, diikuti tombol biru penuh "Lihat Projek ->" di sebelah kiri dan tombol kaca gelap "Hubungi Saya ✈️" di sebelah kanan.   Baris Ikon Sosial Mini: Teks "FIND ME" sejajar dengan 3 tombol ikon kotak gelap untuk GitHub, Instagram, dan TikTok/LinkedIn.   B. Bagian 2: "Hi, I'm" & Foto Interaktif Alter-EgoJudul Perkenalan: Teks "Hi, I'm" berwarna biru gradien di atas nama lengkap "Bagas Puji Ferian" berwarna putih tebal.   Potret Interaktif & Bio Lengkap: Foto potret dengan efek overlay topeng/kostum Spider-Man dan lingkaran radar halus, diikuti paragraf deskripsi diri di bagian bawah.   C. Bagian 3: Education, Experience & Kartu Statistik Angka BesarKartu Education & Experience: Daftar kartu kaca gelap berisi logo institusi di sebelah kiri, nama sekolah/kampus atau perusahaan, subjudul jenjang/jabatan, dan tahun periode berwarna biru.   Tiga Kartu Statistik Metalik: Kartu lebar penuh dengan ikon di kiri atas, angka ukuran besar di kanan atas, judul huruf kapital (PROJECTS, CERTIFICATES, AWARDS), dan subjudul bahasa Indonesia (Karya yang dibuat, Skill yang divalidasi, Pencapaian diraih).   D. Bagian 4: Widget Musik Spotify ("A little music. A lot of ideas.")Kartu Musik Ngoding: Menampilkan judul "A little music." (putih) dan "A lot of ideas." (biru), deskripsi singkat, tombol "🎵 Daily Rotation di Spotify ↗", serta pemutar embed playlist Spotify bertema gelap.   E. Bagian 5: Showcase Portofolio 4-Tab & Halaman Detail ProyekSegmented Control 4-Tab: Navigasi tab kapsul dengan ikon di atas teks untuk berpindah antara Projects (</>), Certificates (🎖️), Achievements (🏆), dan Tech Stack (🔲).   Kartu Proyek & Halaman Detail (/project/{slug}): Kartu proyek menampilkan gambar preview, judul, ringkasan, dan tombol "Details ->". Saat diklik, halaman detail menampilkan banner aplikasi di atas, judul besar, paragraf deskripsi utuh, dan bagian </> Technologies Used berisi badge logo teknologi berwarna.   F. Bagian 6: Formulir "Hubungi saya" & Kartu Sosial "FIND ME"Formulir Kontak Rekruiter: Kartu berisi subjudul biru "Hubungi", input berikon untuk Nama, Email, dan Pesan, serta tombol biru penuh "✈️ Kirim Pesan".   Kartu Tautan Sosial Lebar: Daftar kartu vertikal di bawah label "FIND ME" untuk Instagram, TikTok, dan GitHub lengkap dengan logo resmi, username @..., dan panah ↗.   G. Bagian 7: Buku Tamu Publik (Komentar)Formulir Komentar & Upload Foto: Menampilkan total komentar Komentar (total), input Nama, textarea Komentar, area unggah "🖼️ Pilih Foto Profil" (maksimal 5 MB), dan tombol "✈️ Kirim Komentar".   Daftar Komentar Scrollable: Menampilkan daftar komentar dengan scrollbar vertikal, avatar bulat, nama tebal, isi komentar, dan keterangan waktu relatif bahasa Indonesia (1 jam lalu, 3 hari lalu).   H. Bagian 8: Tombol Utilitas Melayang & FooterFloating Action Button & Footer: Tombol bulat melayang di kiri bawah layar untuk pengatur mode interaktif, ditutup dengan footer >_ Bagas.dev dan teks hak cipta © 2026 BagasDev. All rights reserved..   4. Skema Database MySQL (8 Tabel Utama)Sistem database menggunakan 8 tabel relasional untuk menyimpan seluruh konten halaman:profiles: Menyimpan nama, daftar teks typewriter, bio Hero, bio About, URL foto kartu ID, URL foto Spider-Man overlay, URL playlist Spotify, dan file audio latar.educations: Menyimpan institution, degree_label, period, logo_url, dan sort_order.   experiences: Menyimpan company, role, period, logo_url, sort_order, dan deleted_at (SoftDeletes).   projects: Menyimpan title, slug, thumbnail_url, short_description, full_description, tech_stack (JSON berisi nama & ikon teknologi), demo_url, repo_url, dan deleted_at.   certificates: Menyimpan title, issuer, issue_date, image_url, credential_url, dan type (certificate atau achievement) untuk mengisi tab Certificates dan Achievements.   skills: Menyimpan name, icon_url (Devicon SVG), category, dan sort_order untuk mengisi tab Tech Stack.   contact_messages: Menyimpan name, email, message, is_read, dan deleted_at dari form Hubungi Saya.   public_comments: Menyimpan name, comment, avatar_base64, is_approved, dan deleted_at untuk fitur buku tamu publik
